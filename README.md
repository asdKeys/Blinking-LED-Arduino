# [ARDUINO]Blinking LED

## About

A blinking LED.

## How to Use

First, download the Arduino IDE if you don't have it. Then, go to the file called "Blink_No_Delay.ino" and copy and paste that into the Arduino IDE. The wiring is listed below with a diagram.

## Building

### Parts Needed

- Any Arduino board.
- A breadboard.
- An LED (any color).
- A 220 ohm resistor.
- 4 wires.
